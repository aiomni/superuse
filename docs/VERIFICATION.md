## 网络速率持续不可用修复（2026-10-09）

- `NET_RT_IFLIST2` 的结果包含接口统计与地址消息；旧实现要求每条消息至少有 `if_msghdr` 的长度，较短的正常地址消息会使整次解析失败，重置网络基准并持续显示 —。本机只检查消息类型 / 长度，确认旧检查确实拒绝正常地址消息，未记录地址或实际流量。
- 改为先解析共用四字节头，只对 `RTM_IFINFO2` 检查完整统计结构，其他有效消息按声明长度跳过。严格检查长度与版本，保留 64 位计数器、物理接口筛选及速率基准；接口变化引起缓冲区增长时最多重试三次。
- 相关 15 项测试通过（4 项核心、11 项 AppKit / 采样测试），无编译警告。新增混合消息前后顺序、64 位收发速率、空闲 0 B/s、虚拟 / 未运行 / 回环接口排除，以及截断 / 非法长度和版本回归；真实系统契约测试要求第二次网络采样有效。
- 使用当前实现的读取与解析函数做本机被动连续采样检查，确认活跃物理接口统计可读，并观察到非零下载和上传差值。仅输出成功与否，未保存接口地址、流量数值或发送测试流量；未验证用户菜单栏内的实际显示或 VPN / 网卡切换场景。
